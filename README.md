# Student Registration System

Production-ready student registration platform for Tanta University.

---

## ⚡ START IN ONE COMMAND

```bash
bash quick-start.sh
```

Opens: **http://localhost:3001**

The script auto-copies `.env.docker` to `.env` for local defaults (ports 3000/3001, Postgres password `postgres`).
